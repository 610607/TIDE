# Permission forks for an observed natural transmission

This follow-up was specified after the replication census and product trace identified seed 2437. It reuses the same independent field runs and adds no seeds. For every prospective ordinary case meeting the primary birth criterion, select the original focal and each of its actual intact daughters copied entirely from the original living donor. Use their site and birth tick. Reconstruct each individual's committed birth state with the reference VM. Follow it through age death under ordinary permissions, denial only of external reads from its own reservation, and denial of every external read. Apply each permission change only to the focal's attempted copy instruction.

Compare the ordinary lifetime births with the field pedigree, including tick, child site, copy inputs and product. Report the founder and each daughter separately. Report all three branches even if there is no effect. This is a within-case attribution test for a sample selected on its observed outcome. The full-field untreated event and seed counts come from the prespecified census. The assay code is the geometry study's field fork with the input validator extended to the new seed range.

Two further descriptive checks use the same archived field. Read the focal's and donor's birth inputs and parents from the geometry field observer. Apply the existing pilot pair criterion and 4,096-tick serial assay to all read-exposed mother–daughter–grandchild events of the selected founder, using each parent's own first-contact background. Retain non-live first contacts and exact cycles. These checks were added after inspecting the field births.
