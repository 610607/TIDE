# Identify displaced living sources during a copy

Supplement specified after scoring world-level handoff in the two cohorts and before classifying individual supplier switches. Keep all fields, seeds, cutoffs and VM transitions in the paired protocol. Use the archived switch denominator: every allocation whose first successful write read a different living individual with a different genome. Count each allocation once at its first subsequent successful write from any other identity or an inactive bank. The previous successful write must have read the starting donor.

Log both read ticks and addresses, the original donor's opening location at the second read, the incoming source identity or inactive bank, and the executor and write offset. Categorize each switch first by whether the address changed. For same-address switches, distinguish the original donor still alive at a different site from a donor whose age death already committed. A same-address change while the donor is still alive establishes displacement under the exchange rule. A same-address read after death allows either prior displacement or uninterrupted residence until death. The categories describe the sequence of observed successful writes. Failed reads, censored allocations and changes that reverse before the next successful read are outside this count.

Require record counts to match every previously measured field switch count. Reproduce the primary data without changes and independently replay the additional table. This diagnostic includes all qualifying allocations throughout the field and can explain loss of read continuity. It does not identify the cause of a missing individual handoff.
