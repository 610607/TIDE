# Opportunities for another executor after the original executor dies

Freeze the observer before collecting neighborhood counts. Use baseline 50cf4b1 and every enrolled unlike-executor birth in the four archived stationary bearing arms. Replay seeds 19521–21568 to tick 2048 using the original rules. Identify individuals by site and birth tick. The primary denominator is every enrolled template with a complete lifetime, including templates with zero contacts or successful reads. Retain late births separately, including windows that never opened by the cutoff. Keep the two seed blocks and the four arms identifiable.

For a template born at tick b and original executor born at tick m, inspect the opening state of instructions m+82 through min(b+81, 2048), inclusive. Death commits at age 81, so the template can still supply a read on its own death tick. Consider only other living cardinal neighbors; a new occupant of the original executor's site is eligible. For each pair record identities, observed overlap, presence of S in the neighbor's program, current read bearing, any free neighbor, an owned allocation, and a source pointer directed to the focal site. Count actual reservation attempts while facing the focal template, including failure due to crowding and competition. Geometric facing and an already selected source are separate measurements. A site labeled free may contain retained bytes.

Report a nested series for each focal individual: a living neighbor; an S-bearing neighbor; such a neighbor holding any allocation; such an allocation with its source pointer on the focal; a successful first write from aligned offset zero of that live focal; all six aligned reads from the same focal in that allocation; and an intact birth from those six reads by tick 2048. Deduplicate by focal individual within each stage, requiring the same actor for the downstream stages of a given attempt. Trace writes from an eligible start through division, actor death or cutoff, even if the template subsequently dies. A copy substitution may allow all six aligned reads without an exact birth. Separately report how many focal individuals ever had a facing S-bearing neighbor with an owned allocation or a free neighboring site at the same opening. These frequencies describe actual opportunities under the VM rules.
