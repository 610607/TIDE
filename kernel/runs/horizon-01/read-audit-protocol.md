# Follow-up on the missing data-read links

Declared after the horizon study found zero eligible field pairs in the read arm across all three cohorts. This is a descriptive audit of the same 64 read-only field runs. Keep the data-read incidence and its original field screen intact.

- Stream every attempt and birth, including seeds with zero external reads. Reconcile counts against each original field summary. Identify every birth after the mother's first successful external read. For that particular reservation, retain the ordered input and output bytes and the sites and types of banks that supplied them. Compare the product to its mother and to the as-read inputs before copy substitution.
- Follow each such daughter from birth through death or tick 512. Count births, successful external reads and births following its own first external read. Record elapsed field observation time and whether it was alive at the cutoff.
- For mothers whose first successful external read was from an occupied bank, replay the mother's newborn genome using the same reconstructed donor, permission fork, three-generation transfer, ancestor controls and 4,096-tick horizon. Save per-generation products and actual read use. Compare successful reproduction in the first generation to read use in the daughters. Report mothers and events separately when one CPU has multiple births.
- Report free and reserved bank first contacts outside the live-donor assay. This analysis measures loss of read behavior along observed paths. It does not estimate incidence on new seeds.
